# Ecosystem Modeling of Kaptai Lake, Bangladesh

This repository contains the datasets, model parameters, analytical scripts, and raw figures for the study: **"Ecosystem Modeling of Kaptai Lake, Bangladesh: A Trophic Mass-Balance Approach using the Ecopath Framework."**

## Overview
Kaptai Lake is the largest reservoir in Bangladesh. This project utilizes a mass-balance ecosystem model (Ecopath with Ecosim v6.6.8) integrating a decade of catch data (2010–2020) to evaluate the ecosystem’s structural stability, trophic interactions, and maturity. The data provided here serves as a quantitative baseline for predicting ecosystem shifts and supports sustainable fisheries management.

## Repository Structure

*   `Data/` - Contains the raw empirical data, including the 10-year annualized catch data and morphological parameters for the 13 functional groups.
*   `Graphical Abstract/` - Contains graphical abstract of the manuscript.
*   `illustration/` - Contains graphical assets and visual elements used in the ecosystem model diagrams and manuscript.
*   `Model/` - Contains the Ecopath basic inputs, diet matrices, and pre/post-balancing parameter adjustments.
*   `Plots/` - High-resolution image files of the analytical outputs (e.g., food web diagrams, Mixed Trophic Impact charts, and niche overlap plots).
*   `R code/` - Contains the R programming scripts utilized for ecological data visualization and statistical analysis.
